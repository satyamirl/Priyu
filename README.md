## Overview

**Priyu** is a feature-rich Discord bot designed to enhance both voice and text communities. From advanced music playback to automated server messages and customizable embeds, Priyu provides server owners with tools to personalize and manage their communities.

Built with flexibility, performance, and customization in mind, Priyu brings music, engagement, and server management together in one platform.

## Features

### Music System

- High-quality audio streaming powered by Mafic and Lavalink.
- Queue management, looping, seeking, autoplay, and 24/7 voice channel functionality.
- 15+ real-time DSP audio filters, including 8D, Bass Boost, Lo-Fi, Nightcore, and Vaporwave.
- Personal favorites and persistent custom playlists.

### Server Identity Customization

- Customize the bot's avatar, banner, nickname, and server bio for individual communities.
- Tiered access with voting requirements and claim limits.
- Timed and lifetime premium activations.

### Automated Messaging and Greetings

- **Autoresponder:** Configure automatic responses to matching messages and keywords.
- **Welcome Messages:** Send customized greetings when new members join.
- **Leave Messages:** Automatically send messages when members leave.
- **Boost Notifications:** Celebrate server boosts with customizable messages.
- **Greeting Commands:** Configure server greeting features to suit your community.

### Custom Embed Builder

- Create customized Discord embeds for announcements, information, rules, and other server messages.
- Personalize embed content and presentation.
- Use variables to insert dynamic information into embed messages.
- Reuse customized messages for different server needs.

### Community Interaction

- 40+ anime-inspired reaction and roleplay commands.
- Interactive actions such as Hug, Cuddle, Dance, Pat, and Slap.
- Community-focused features designed to keep text channels engaging alongside voice sessions.

### Protection and Reliability

- Automated spam detection and strike tracking.
- Guild raid alerts and rate-limit monitoring.
- Support-server notifications for critical protection events.
- Gateway latency, SQLite query speed, and REST API performance diagnostics.
- Live telemetry for playback activity, command statistics, system metrics, and critical exceptions.
